# Project working preferences

Read DESIGN.md before UI work. The owner's approved direction is the existing minimal cozy Roomie Match style, centered lowercase wordmark, existing colors, varied motion and scale, and profile-first Discovery.

Prefer small focused Git commits; a larger cohesive commit is fine occasionally. Checkpoint design iterations, including rejected experiments, instead of waiting for a polished final result. Label unfinished checkpoints honestly and verify functional changes. Do not push without authorization. Preserve unrelated changes.
